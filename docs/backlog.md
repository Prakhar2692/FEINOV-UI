# Implemented versus planned backlog

## Implemented features

- App bootstrap and environment-aware configuration
- Router setup and app shell navigation
- Material 3 design system and shared widgets
- Authentication flow scaffolding and controllers
- Product listing and detail experience
- Category and subcategory browsing
- Cart behavior and checkout flow structure
- Search, recent searches, and suggestions
- Orders and profile data models
- Wishlist support
- Payment integration scaffolding
- Native platform scaffold for Android, iOS, Linux, macOS, and Windows
- Smoke tests and model validation tests

## In progress or partially implemented

- Final API contract alignment with backend services
- Custom release configuration for production signing
- Payment callback validation for live gateway integration
- Search pagination and filtering refinement
- Enhanced profile and address edit flows

## Planned / not yet implemented

- Deep analytics and event tracking
- Push notifications
- Review and rating system
- Multi-language support beyond the base locale setup
- Loyalty and referral logic
- Seller/admin dashboard
- Advanced recommendation logic
- Offline-first caching strategy

## Definition of done

A feature is considered done when:

- the domain and data layers are implemented
- the controller/provider wiring is complete
- the UI is accessible and responsive
- error states are handled
- tests cover the logic and smoke flow
- the backend contract is validated in the target environment
