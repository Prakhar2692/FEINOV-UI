# Product roadmap

## Phase 1: foundation and architecture

Completed:

- Flutter app shell and bootstrapping
- core theme, spacing, colors, and reusable widgets
- dependency injection and router setup
- environment switching for development/staging/production
- network client, error handling, and service entry points

## Phase 2: commerce core

Completed:

- authentication flows
- product catalog and category browsing
- search and suggestions
- cart management
- wishlist experience
- orders and profile handling
- checkout and payment integration scaffolding

## Phase 3: polish and release readiness

Planned:

- final backend contract validation
- release signing and app distribution setup
- analytics and crash reporting
- push notifications and retention flows
- performance optimization and accessibility review
- translations and locale expansion

## Phase 4: growth features

Planned:

- loyalty and rewards
- reviews and ratings
- recommendations engine
- subscription and repeat-order flows
- admin or seller console
- personalized onboarding journey

## Delivery guideline

The app is currently structured as a production-oriented storefront foundation with a feature-complete front-end layer and a backend-integration path ready for final contract alignment.
